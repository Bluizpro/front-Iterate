<h2 align="center">Descrição</h2>

<p align="center">
  Este é um sistema web para o gerenciamento de encomendas em condomínios. Permite registrar, rastrear e gerenciar encomendas internas, sedex e externas.
</p>

## Funcionalidades

- Registro de encomendas
- Rastreamento de encomendas
- Notificações de chegada de encomendas
- Relatórios de encomendas recebidas e enviadas

## Instalação

1. Clone o repositório.
2. Instale as dependências usando o comando `npm install`.
3. Inicie o servidor de desenvolvimento com `quasar dev`.

## Uso

Para usar o sistema, basta acessar a interface web. É possível filtrar as encomendas por tipo (interno, sedex, externo) e visualizar detalhes de cada uma.
